# シバイヌおやびんのデイトレ道場

先物などの過去の5分足を1本ずつ再生しながら、ロング／ショートでデイトレを練習するブラウザゲームです。1日の終わりに損益を表示し、成績を積み上げていけます。

**▶ 遊ぶ：** https://shibainuoyabin.github.io/nq-daytrade-dojo/

## 値段のデータについて

このゲームには、値段のデータが入っていません。遊ぶ人が自分で用意した5分足（または1分足）のCSVファイルを読み込んで遊びます。

- 読み込んだファイルは、**あなたのブラウザの中だけ**で使います。どこにも送信・アップロードされません。
- 一度読み込めばブラウザに保存されるので、次からはそのまま遊べます。
- CSVがなくても、**サンプル（架空の値動き）**ですぐに試せます。

データの用意のしかた（TradingView から書き出す手順など）は、ゲームの「データ」ボタンから開く画面で詳しく説明しています。TradingView の「チャートデータのダウンロード」は、有料プランの Plus 以上で使えます（無料の Basic と Essential では使えません。2026年10月時点の[料金ページ](https://www.tradingview.com/pricing/)で確認）。データは、入手元（TradingView・証券会社など）の利用規約の範囲で使ってください。

### 読み込めるCSV

- 1行目に列名があり、時刻・始値・高値・安値・終値（出来高は任意）の列があるもの
  - 列名の例：`time` `datetime` `date`＋`time` `open` `high` `low` `close` `volume`、`始値` `高値` `安値` `終値` `出来高`
- 時刻：UNIX 時間、タイムゾーン付きの ISO 形式、タイムゾーンなしの日時（どこの時間かを画面で選ぶ）
- 区切り：カンマ・セミコロン・タブ
- 5分より短い足（1分・2分・3分足など）は、自動で5分足にまとめます

## 遊び方

1. 「データ」でCSVを読み込む（またはサンプルを選ぶ）
2. 時間帯（本場／先物の1日）と日付を選んで開始し、「スタート」で再生
3. 再生しながら売買する。時刻は日本時間で表示します

| キー | 操作 |
|---|---|
| B | ロング |
| S | ショート |
| X | 決済 |
| R | ドテン |
| Space | 再生／停止 |
| → | 1本送り |

## 主な機能

- 速度調節（0.05〜5秒/本）、足の途中の値動きの再現（始値→高値・安値→終値をなぞる作りものの動きで、実際の順番ではありません）
- 銘柄の設定（MNQ・NQ・MES・ES・MCL・CL・MGC・GC、または任意の1pt価値と呼び値）、手数料の設定
- SMA×3、ボリンジャーバンド（中心線・±1σ/2σ/3σ を個別にオンオフ）、VWAP
- 左下のステータスパネル（VWAP・MA・MAの傾き・日足の判定）
- 1日の結果（総損益・勝率・最大ドローダウン・トレード一覧）と、累計の成績・履歴（ブラウザに保存、リセット可）
- 再生中のループBGM、売買の効果音（Web Audio で合成）

## ファイル

- `dataio.js` … CSV の読み取りと変換、サンプルの作成、ブラウザ内への保存
